Dutchman Bridge provides two ways to fund a customer's fiat wallet balance: a **virtual bank account** that accepts standing bank transfers at any time, and **funding charges** that initiate a one-off bank transfer or an EFT redirect for a specific amount. Choose the method that best fits your product experience — many integrations offer both.

## Method 1: Virtual Bank Account

Each customer is assigned a dedicated virtual bank account in their local currency. The customer can transfer funds to this account from any bank at any time; Dutchman Bridge detects the incoming transfer and credits the wallet automatically.

**Retrieve the virtual account details**

```bash
curl https://app.dutchmannetwork.online/api/v1/partner/v1/customers/cust_abc123/virtual-account \
  -H "x-api-key: YOUR_API_KEY"
```

**Response**

```json
{
  "success": true,
  "data": {
    "accountNumber": "0123456789",
    "bankName": "Wema Bank",
    "accountName": "Dutchman / Ada Obi",
    "currency": "NGN"
  }
}
```

Display the `accountNumber`, `bankName`, and `accountName` to your customer. They can use these details for any future transfer — the account is permanent and reusable.

## Method 2: Funding Charges

A funding charge initiates a one-off deposit request for a specific amount. For NGN, you receive bank account details to present to the customer. For ZAR, you receive a redirect URL that the customer must visit to authorize the EFT payment.

**Initiate a funding charge**

```bash
curl -X POST https://app.dutchmannetwork.online/api/v1/partner/v1/customers/cust_abc123/funding/charge \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 10000,
    "currency": "NGN",
    "method": "bank_transfer"
  }'
```

The `method` field accepts `"bank_transfer"` for NGN one-off transfers and `"eft"` for ZAR EFT redirects.

**List funding charges**

```bash
curl https://app.dutchmannetwork.online/api/v1/partner/v1/customers/cust_abc123/funding/charges \
  -H "x-api-key: YOUR_API_KEY"
```

Charge lifecycle statuses: `pending` → `completed` or `failed`. Listen for webhook events to react to status changes without polling.

## Checking Credit

After a deposit is confirmed — whether via virtual account or funding charge — the customer's fiat balance is updated immediately. Retrieve the latest balance at any time:

```bash
curl https://app.dutchmannetwork.online/api/v1/partner/v1/customers/cust_abc123/balance \
  -H "x-api-key: YOUR_API_KEY"
```

**Response**

```json
{
  "success": true,
  "data": {
    "fiat": {
      "amount": "10000",
      "currency": "NGN"
    },
    "usdt": {
      "amount": "0.00"
    }
  }
}
```

For real-time credit notifications without polling, configure a webhook endpoint to receive deposit events. See the [Webhooks guide](/guides/webhooks) for setup instructions.
